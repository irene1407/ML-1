Can Search Performance Signals Predict Ranking Deterioration?

Investigating whether historical search-performance signals can identify content at risk of ranking deterioration using machine learning.

E Shirley Iren November 17, 2026 FlyRank ML Internship Capstone
Explore the findings ↓ View source code ↗

01 / ABSTRACT

The research question

Can March 2026 search-performance signals help identify client-content pairs whose average search ranking deteriorates in April 2026?

This study uses anonymized historical performance data, a rule-based baseline, Logistic Regression and Random Forest. Models are evaluated using a client-grouped train-test split to assess performance on previously unseen clients.

Logistic Regression achieved 0.6626 ROC-AUC, 0.8557 Average Precision and 96% Precision@100. It outperformed the baseline at the evaluated top-ranking cutoffs, although the results remain specific to this validation sample.

02 / PROBLEM

Turning search signals into useful priorities

Search-performance data contains signals such as impressions, clicks, click-through rate and average position. The challenge is identifying which client-content pairs may need closer investigation.

06 / LIMITATIONS

What these results do not prove

  • Results describe one grouped validation sample, not guaranteed future performance.
  • The grouped test set contains only 10 held-out clients.
  • Average position is closely related to the target construction and contributes substantially to model performance.
  • The baseline selected only 38 test items with non-zero scores and had 0.20% recall.
  • Predicted associations do not establish causality or prove that editorial changes improve rankings.
